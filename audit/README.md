# Audit materials

This directory mixes the current review package with explicitly dated
historical evidence. Start with:

1. [`ILAL_CURRENT_AUDIT_SCOPE.md`](ILAL_CURRENT_AUDIT_SCOPE.md)
2. [`AUDIT_PACKAGE_INDEX.md`](AUDIT_PACKAGE_INDEX.md)
3. [`../docs/data-room/THREAT_MODEL.md`](../docs/data-room/THREAT_MODEL.md)

Files carrying older version numbers or dated remediation titles are retained
for provenance. They are not current deployment or test-status authorities.
When documents disagree, use source code for behavior, the active deployment
manifest for chain state, and `ILAL_CURRENT_AUDIT_SCOPE.md` for review scope.
