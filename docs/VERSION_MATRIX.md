# ILAL implementation status

There is one maintained implementation: **ILAL v1**. It combines eligibility, reusable grants, atomic netting and LP ownership. `Mixed*` remains an internal compatibility name for its deployed contracts and signed wire format.

- Current source/package status: [protocol.json](../protocol.json).
- Current candidate evidence: [Base Sepolia manifest](../deployments/base-sepolia/v1.0.0-mixed-testnet.1.json).
- Behavior: [specification](mixed/SPEC.md).
- Prior releases and compatibility: [history](HISTORY.md).

The candidate remains unaudited, CNF_ONLY and testnet-only. Source consolidation is not an on-chain upgrade or stable-release promotion. The retained deployment index records historical release status and does not select defaults for the current CLI.
